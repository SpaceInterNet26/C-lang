# Arrays
single type data set. Arrays reserve space in memory for data.
arrays can be single dimensional, two dimensional ect.
arrays can be stored with a loop or thru constants.
first element index is 0.
they can be a function argument.

### Array prototype
- type _array-name_[array_size]
## Single Dimensional
stored consistently one after another.

## Two Dimensional
stored in rows.

# Pointers
variable - memory segment that has a name. A computer reaches its memory thru addresses, not names. that is where pointers come into play.
A pointer is a variable which holds memory address. We can say a pointer points to a variable, whose address its holding.
pointer is defined similar to a variable, for example, int *ptr.
'&'- brings back variables address.
'*'- de-referencing operator.
if used on an array, pointer will point at the first element. For array calling into functions mostly pointers are used.
## Main rules for pointers usage
- defining a pointer '*' is written before its name.
- wanting to get variables address, write '&' before variables name.
- wanting to get variables, to which a pointer is pointing, definition, before pointers name '*' is written.

# Reference
its a special data type (hidden pointer), which automatically works with variables definition when used. It's like a variables second name or pseudonym.

## Reference prototype
- type &reference_name = variables name

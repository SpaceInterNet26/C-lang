# Control statements and functions
## Control statements
- Switch - executes certain code block based on a value of an expression
- Continue - skips a part of loop operators and jumps to a new iteration
- Break - terminates loop
- goto - jumps to code that has been given a label for this statement
## Functions
It's a part of a program code that has its own name. It can be called from any other program.
we use functions to:
- have clear algorithm structure
- partition a program
- easily use a part of a program several times

return type and function type has to match. Function could be of _void_ data type.
### Function prototype
type *function_name* (Argument list){ code block };

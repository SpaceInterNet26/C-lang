# Variables and Data types

Variable is a name to a value that can be changed. Differently than a constant whose value can't be changed.
Also there are different data types that variables get assigned to. There are two types of variables - Local and Global. 
## Main Data Types
1. Integer - for rational number usage, for example - 5 , 6 , 7 .
2. Float/Double - for irrational number usage, for example - 6.54 , 3.145 . 
3. Bool - for true/false usage.
4. char - for character usage.

## Other Data types
- unsigned/signed integer
- long/short integer
- void
### Local and Global variables
-**Local** - created inside functions and can only be used inside functions. After a function ends local variables are destroyed.
-**Global** - created outside functions and works throughout programs runtime.
## Modificators
1. *Auto*
   - used to define local variables
2. *Register*
   - stored local variable into processors registers.
3. *Extern*
   - variable usage between main file and header.
4. *Static*
   - exists until the program stops running
